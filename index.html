Blackboard Integration Guide
This Studio system is designed to embed seamlessly into your Blackboard module page as a web tool. Follow the steps below for each method.

Method 1 — Embed as Web Link (Recommended)

  1. In your Blackboard module, go to Content → Build Content → Web Link
  2. Name it: Digital Transformation Studio
  3. Paste the Studio URL below into the URL field
  4. Check "This link is to a Tool Provider" if available
  5. Check "Open in New Window" for best experience
  6. Set availability to students and click Submit

Your Studio URL (copy this into Blackboard)

https://tertsegha1.github.io/cmp701-studio/

Method 2 — Embed as iFrame in a Blackboard Item NOT RECOMMENDED

  1. Go to Build Content → Item
  2. In the text editor, click the HTML source button (</>)
  3. Paste the iframe code below
  4. Click Submit
<iframe src="https://tertsegha1.github.io/cmp701-studio/?role=student" width="100%" height="800" frameborder="0" allow="clipboard-write" style="border-radius:8px;border:none"> </iframe>

Method 3 — Separate Student Access Link

Share this direct link with students via Blackboard Announcement or email. It opens in Student View automatically:

https://tertsegha1.github.io/cmp701-studio/?role=student

Lecturer / Tutor Access Link

Share this link with seminar leaders, visiting lecturers, and tutors. It opens in Lecturer View — they can see submissions, run AI assessment, and post announcements, but cannot change configuration or manage cohorts.

https://tertsegha1.github.io/cmp701-studio/?role=lecturer

For a specific cohort: use the Copy Lecturer Link button on the cohort card in the Cohorts tab — it appends the cohort ID automatically.

AI Configuration (Module Leader)

Enter your Anthropic API key once here. It is stored in your browser only and used silently by all AI features — lecturers and students never see or need to enter it.

Never stored in Firebase. Stays in this browser's localStorage only.

Teaching Team

Members listed here can access Lecturer View. When a team member opens the lecturer URL, they must select their name from this list before proceeding. Update this list at the start of each semester.

Removes all members — use at the start of each semester before adding the new team.

Student Identification

Students select their name from a dropdown when they first open the Studio. Their progress is then tracked under their name in the Submissions tab above.

Blackboard does not automatically pass student identity to external tools unless you use LTI. For LTI integration, contact your Blackboard administrator to register this tool as an LTI provider.
Module Configuration
Each cohort is a fully isolated semester/intake — its own students, guilds, quests, submissions, deadlines and announcements. Switch cohorts from the header dropdown; Lecturers access via the shared Lecturer link.
